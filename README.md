# SHA-256-implementation

# overview:
This project implements the SHA-256 algorithm in C++ to generate a unique hash for any given text.it for data integrity and security.

Features:
Takes user input and produce the 256-bit hash value.
it displays output in a readable hexadecimal format.

Output example:
Plz enter the hash text (SHA-256): hello

This is the hash result buddy: 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
